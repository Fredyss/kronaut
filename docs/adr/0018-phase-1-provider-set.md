# ADR-0018: Phase 1 provider set

- **Status:** Superseded by ADR-0052
- **Date:** 2026-10-21
- **Deciders:** Frederik Schlentc
- **Area:** Providers & product
- **Spec:** [Roadmap](../architecture/09-roadmap.md)

## Context

Core before breadth; each provider costs an error map, verify logic, fixtures and review upkeep.

## Decision

**Phase 1 = 6 providers**: Bluesky, Instagram (feed/carousel/Reels), Facebook Page, Threads, Mastodon, LinkedIn personal (+ Telegram only if ≤ 2 days)

## Options considered

- **Chosen:** the decision above.
- Rejected: 10 providers

## Consequences

- Revisit when: a paying design partner needs one
